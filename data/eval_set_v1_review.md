# eval_set_v1 정답·채점 검토

검토 대상: `data/eval_set_v1.json`의 33개 항목, `scripts/ablation.py`의 `check`, `scripts/dataset_count_votes.py`의 `EXACT`.

현재 자료는 개발용 초안으로 쓸 수 있지만, 그대로 논문용 정답으로 확정하기에는 문제가 있다. 원본 데이터와 채점 코드는 이번 검토에서 수정하지 않았다. 아래 권고도 연구자가 검토해야 하는 주석안이다.

**정답의 단위를 먼저 변경해야 한다.** 문장에 명시된 동작 횟수와 렌더러의 짧은 진동 구간 수는 다르다. 한 번 구기는 동작은 여러 파형 피크를 포함할 수 있고, 세 번의 압박은 하나의 변조된 연속 신호로 표현할 수도 있다. `duration <= 0.6` 및 `transition == cut`은 현재 구현의 구간 분류 조건이며 물리적 접촉의 정의가 아니다. 명시적 횟수는 해당 동작에 한정하여 채점하고, 파형의 피크 검출 성능은 별도로 평가해야 한다.

**표의 의미:** ‘유지’는 문장의 해당 의미 조건을 유지할 수 있다는 뜻이다. 기존의 전역 `contacts` 검사까지 타당하다는 뜻은 아니다. ‘조건부’는 표현 방식·해석·설계 의도가 추가로 필요하므로 엄격한 정답으로 바로 쓰지 말아야 한다는 뜻이다.

**채점 코드에서 재현한 문제**

아래는 LM을 호출하지 않고 `ablation.check`에 의도적으로 잘못된 계획을 넣어 확인한 결과다.

1. s13에 ‘지퍼 닫기 → 뒤적이기 → 지퍼 열기’를 입력해도 `phases=true`였다. 두 지퍼 그룹이 모두 `zip`을 OR 조건으로 허용하기 때문이다.
2. s06에서 ‘진입 껍질 → 과육’만 출력하고 출구 껍질을 생략해도 `phases=true`였다. 출구 단계가 정답 주석에 없기 때문이다.
3. c12에서 압박 시작 시각을 `[0, 0.1, 0.7, 1.8]`초로 주어 간격을 `[0.1, 0.6, 1.1]`초로 만들었는데 모든 검사를 통과했다. 중앙값 0.6초만으로 일정한 박자를 판단하기 때문이다.

추가로 `intensity` 설명은 짧은 사건들을 대상으로 한다고 되어 있지만, 실제 코드는 모든 구간의 첫·마지막 강도를 비교한다. `continuous`도 어떤 동작의 지속성을 확인하지 않고 긴 구간 하나의 존재만 확인한다. `0.5~0.6`초 cut 구간은 현재 정의상 짧은 접촉과 연속 구간 양쪽으로 집계된다. `renderable`은 생성 가능성 검사이며, 의미 정확도와 같은 가중치로 섞은 총점을 의미 정확도로 부르면 안 된다.

키워드 OR 매칭은 진단용 보조 도구로 유지할 수 있지만 정답 의미 매칭의 대체물은 아니다. 물체명과 동작을 구분하고, 반복 횟수와 강도 조건을 대응하는 사건에만 적용해야 한다. 무음 물리 단계는 진동 sub-event가 아닌 계획의 물리 단계에서 확인해야 한다.

**데이터 분할과 논문에서의 사용**

- c07/c08, s02/s03, s09/s10, s15/s16, s18/s19, s05/s20은 같은 동작 계열의 가까운 변형이다. 같은 계열을 개발용·시험용 양쪽에 나누지 않는다.
- 현재 본 문장과 결과를 보며 프롬프트·채점기를 수정했다면 이 33개는 개발·회귀 검사셋으로 취급한다. 최종 시험셋은 새로운 문장·동작 조합으로 따로 고정해야 한다.
- 원문이 공개 HapticGen 자료라는 사실이 사건 분해 정답까지 검증됐다는 뜻은 아니다. 원문 출처와 우리가 추가한 주석의 출처를 구분한다.
- 항목마다 `expertvoted`/`uservoted`, 원본 메타데이터 경로와 데이터 버전을 기록한다. `expertvoted`는 HapticGen의 학습에 사용된 자료라는 점을 평가 설명에 반영한다.
- 연구자가 명시 조건·해석 조건·설계 가정을 구분해 검토하고, 가능하면 독립된 추가 주석자의 검토와 불일치 조정을 거쳐 정답을 확정한다.

우선 확정할 수 있는 조건은 c01/c02/c04/c07/c08/c11의 동작별 횟수, c12의 목표 주기, s12의 단계 간 상대 강도, 명시된 순서·무음·출구 단계다. 모호한 접촉 총수나 전역 최대 강도는 미채점으로 두는 편이 타당하다. 이 자료는 물리 파라미터 정답이나 최종 파형의 지각 품질 정답을 제공하지 않는다.
