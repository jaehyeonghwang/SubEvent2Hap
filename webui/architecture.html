기본 플래너: LM 사건 분해 (staged)

문장을 시간이 정해진 진동 사건 목록으로 바꿉니다. LM에 네 번 차례로 묻고, 코드는 형식·범위만 검사합니다. 각 LM 단계는 형식 오류가 나면 한 번 수정을 요청하고, 그래도 틀리면 실패로 처리합니다.

LM 호출코드 검사입력

플래너 비교 실험 (ablation)

구성문장진동 생성 성공모든 조건 통과횟수순서LM 호출

생성 성공은 실행 가능 여부만 뜻합니다. 조건 열은 계획이 실패한 문장을 실패로 셉니다. 1회 실행, 정답은 연구자 확인 전 초안입니다.

실험: 모델 우선 계층 플래너 (model_first · 기본 경로 아님)

비교 실험에서 기본 플래너보다 생성 성공률과 조건 통과율이 모두 낮아 기본 경로에서 뺐습니다(UI에서 선택 가능). 하위 단계를 하나씩 꺼도 결과가 나빠지지 않았습니다.
동작 설명 한 문장을 진동 이벤트로 바꾸는 과정입니다. LM이 두 가지 질문에 답하고, 답에 따라 세 경로 중 하나로 갑니다. 여러 단계로 나뉜 동작은 단계마다 이 과정을 처음부터 다시 거칩니다.

LM이 답하거나 작성코드가 계산·검사점선: 선택 단계 · 되돌아가는 경로작은 글씨: 코드 이름

예시 1 · 경로 A

"A rubber ball is dropped and bounces four times."

  1. Q1 수직 바운스 모델(vertical_bounce)이 전체를 설명함 → 경로 A
  2. A1 문장에서 횟수 4 추출
  3. A2 높이·반발계수·질량 추정 (켜져 있을 때)
  4. A3 충돌 4번의 시각과 세기를 계산

예시 2 · 경로 B

"A ball rolls across the floor and hits a wall."

  1. Q1 전체를 한 번에 설명하는 모델 없음 → Q2
  2. Q2 굴러감과 충돌은 접촉 방식이 다름 → 여러 단계
  3. B1·B2 "굴러감" / "벽 충돌"로 나누고 검토
  4. B3 각 단계를 Q1부터 다시 처리 (굴러감 → rolling, 충돌 → single_impact). 굴러간 끝 속도가 충돌 속도로 전달됨

예시 흐름입니다. 실제 분기는 LM 판단에 따라 달라질 수 있습니다.

예외 경로

  • A3 계산 단계에서 고른 모델이 문장과 맞지 않는 것으로 드러나면, 그 모델을 빼고 Q2로 갑니다.
  • Q2에서 한 단계로 판단되면, 남은 모델 중에서 다시 고릅니다. 맞는 모델이 없으면 경로 C로 갑니다.
  • 깊이 3 또는 노드 15개에 도달하거나 같은 설명이 반복되면 더 나누지 않고 경로 C로 마무리합니다.

LM 단계 (코드에서 읽음)

기본 플래너 (decompose.py) — 항상 이 순서로 호출됩니다.

실험용 계층 플래너 (model_planner.py) — 소스에 나오는 순서이며, 실제 호출은 분기에 따라 달라집니다.

파라미터 값 우선순위 (실험용 계층 플래너)

각 물리량은 왼쪽부터 처음으로 존재하는 값을 씁니다. 출처는 결과에 기록됩니다.

LM 추정 대상:
횟수·시각·seed·비율은 추정하지 않습니다.

예외 · 바운스 횟수: 문장에 없으면 기본값 대신 물리로 도출합니다. 충격량이 첫 충돌의 아래로 떨어지면 멈춘 것으로 봅니다. 재생 한도(개·10초)를 넘는 충돌은 출력하지 않고 경고로만 알립니다.

모델 카탈로그 (실험용 계층 플래너)

계층 플래너의 Q1에서 LM이 고르는 모델 목록입니다. 기본 플래너는 이 모델들을 쓰지 않습니다. physical_models.py에서 직접 읽습니다. 한국어 설명은 보기용이고, LM에는 그 아래 영어 원문이 전달됩니다.
파라미터 표시: 추정 문장에 없으면 LM이 추정할 수 있음 · 상속 앞 단계의 계산 결과를 물려받을 수 있음 · 표시 없음: 문장에 있거나 기본값 사용. 마우스를 올리면 정의가 보입니다.
범위: 시나리오 = 여러 번의 접촉을 모델 하나가 한 번에 처리 · 기본 = 동작 하나 · 과정 = 반복·확률적으로 이어지는 동작.
